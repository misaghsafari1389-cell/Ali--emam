# ALI — THE BEGINNING: CHILDHOOD

A 3D historical adventure game built in Godot 4.

This is the first chapter in a larger historical game series, following the early life of Imam Ali (peace be upon him) during his childhood and the beginning of Prophethood in Mecca.

## Game Overview

**Platform:** Android (Mobile)  
**Engine:** Godot 4  
**Game Type:** 3D Historical Adventure  
**Target Length:** ~6 hours (main and side content)

## Project Status

**Phase:** Foundation & Architecture Setup  
**Version:** 0.1.0

## Key Features

- **3D Historical World:** Explore Mecca during Ali's childhood
- **Character-Driven Story:** Learn who Ali is through his actions
- **No Combat:** Focus on meaningful interactions and moral choices
- **Mobile-Optimized:** Built for Android devices
- **Modular Architecture:** Clean, scalable codebase
